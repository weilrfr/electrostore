# Firebase Setup для разработки

## Если вы видите ошибку "Ошибка отправки заявки"

### Причина:
Firestore Security Rules не были обновлены или используются неправильные правила.

### Решение:

#### Способ 1: Через Firebase CLI (рекомендуется)

```bash
# Установить Firebase CLI (если еще не установлен)
npm install -g firebase-tools

# Авторизоваться
firebase login

# Инициализировать проект (один раз)
firebase init firestore
# Ответьте на вопросы:
# - Используйте существующий проект
# - Выберите свой проект technomarket-*
# - Для файла правил: firestore.rules
# - Для индексов: firestore.indexes.json

# Развернуть обновленные правила
firebase deploy --only firestore:rules
```

Если всё работает, вы увидите:
```
✔  Deploy complete!
```

---

#### Способ 2: Через Firebase Console (вручную)

1. Откройте [Firebase Console](https://console.firebase.google.com)
2. Выберите ваш проект
3. Перейдите в **Firestore Database** → вкладка **Rules**
4. Скопируйте содержимое файла `firestore.rules` из проекта
5. Вставьте в редактор правил
6. Нажмите **Опубликовать**

---

## Основные правила для разработки

Если вы разрабатываете локально, можно использовать **тестовый режим** (менее безопасно):

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Позволяет все читать и писать (только для разработки!)
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

⚠️ **НЕ ИСПОЛЬЗУЙТЕ В PRODUCTION!**

---

## Проверка правил

После развертывания, откройте браузер и попробуйте снова отправить заявку. Должно работать.

Если видите ошибку в консоли браузера (F12):
- `permission-denied` → правила не обновлены
- `PERMISSION_DENIED` → пользователь не авторизован

---

## Создание индексов (если потребуется)

Firebase автоматически подскажет, нужны ли индексы при сложных запросах.

При появлении сообщения типа:
```
The query requires an index...
```

Нажмите на ссылку в консоли Firestore или выполните:
```bash
firebase deploy --only firestore:indexes
```

---

## Для администратора

После первой регистрации:

1. Откройте [Firebase Console](https://console.firebase.google.com) → **Firestore**
2. Коллекция `users` → найдите свой документ (по UID из **Authentication**)
3. Отредактируйте поле `role`: измените `"customer"` → `"admin"`
4. Сохраните

Теперь у вас появится доступ к **Панели администратора** (иконка 🔧 в профиле).

---

## Если всё еще не работает

Попробуйте:

1. **Очистить кэш браузера** → F12 → Application → Clear Site Data
2. **Проверить консоль браузера** (F12 → Console) на ошибки
3. **Перезагрузить страницу** (Ctrl+Shift+R)
4. **Проверить, авторизованы ли вы** → должны быть в профиле
5. **Проверить Firebase правила** в консоли на синтаксические ошибки

Если видите ошибку типа:
```
Error: PERMISSION_DENIED
```

Значит правила не обновлены. Выполните `firebase deploy --only firestore:rules` ещё раз.
